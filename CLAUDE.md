# Smith & Winters Electrical - PDF Report Generator

## Project Overview
A web app that takes a SimPRO job PDF, extracts all job data, and generates a branded PDF completion report. Hosted on Railway.

## Tech Stack
- Backend: Node.js + Express
- PDF: Python + ReportLab
- AI: Claude API (claude-sonnet-4-20250514)

## Railway Config
- Env: ANTHROPIC_API_KEY
- Auto-deploy on push to main
